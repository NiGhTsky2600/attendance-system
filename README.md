# attendance-system
“A lightweight attendance management system that allows users to record, monitor, and organize attendance records efficiently.”
============================================================================
features as of now:
user,admin and superadmin - login
time(in/out)
user can add log reports and  concerns
admin and superadmin can reply to those reports and concern 
superadmin has an ability to add admin, promote admin as member and vice versa
user can register if not member and an admin can approve the registration 
=============================================================================
ps: this program is at early stages.
